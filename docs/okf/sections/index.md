# Sections

* [Activity and Notifications](activity-center.md) - Run Activity lists recent cross-module runs with the module, action/profile, status, origin, time, and duration.
* [Agent access (MCP)](agent-access.md) - Automator runs a Model Context Protocol server inside the Electron host so Claude Code (or any MCP client) can use scripts, browser automations and Work Time without anyone starting a separate service.
* [E2E test catalog](e2e-catalog.md) - `docs/e2e/index.html` is a single self-contained page that lists every automated test in the repository by category, and holds the team's ideas for tests that do not exist yet.
* [Global Action Search](global-action-search.md) - Global Action Search appears as the default home surface when the compact launcher opens.
* [Options](options.md) - Options manages application-wide preferences such as the opener key, theme, startup behavior, and settings backup/restore.
* [Workspace window](workspace.md) - Workspace is the larger window for editing complex profiles and reviewing module data.
