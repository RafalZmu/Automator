# Tabs

* [API — slot 3](api.md) - API stores reusable HTTP request profiles.
* [Browser Automation — slot 4](browser-automation.md) - Playwright Test Explorer discovers tests in the managed project or a selected existing Playwright project.
* [Codex — not bound to a slot](codex.md) - Current status: Slot 9 is now Snippets.
* [Launcher — slot 1](launcher.md) - The Launcher binds short letter aliases to installed apps, EXEs, and shortcuts.
* [Quick notes — slot 10](notes.md) - Quick notes keeps short notes written in markdown.
* [Scheduler — slot 6](scheduler.md) - Scheduler creates interval, daily, and weekly schedules in local time.
* [Script Runner — slot 2](script-runner.md) - Script Runner saves reusable Python, Bash, and PowerShell scripts as profiles.
* [Snippets — slot 9](snippets.md) - Snippets saves pieces of text you paste often, such as a tax number or a command like `/plan`.
* [Website Launcher — slot 8](website-launcher.md) - Website Launcher saves named shortcuts with a letters-only alias.
* [Work Time — slot 7](work-time.md) - Work Time logs elapsed work intervals rather than running a Pomodoro cycle.
* [Workflows — slot 5](workflows.md) - Workflows chain saved Script Runner, API, Browser Automation, and Codex-generated Playwright task profiles.
