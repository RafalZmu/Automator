# Workspace and Productivity Upgrade Progress

**Status:** Implemented and verified on 2026-10-03.

## Delivered

- API tab uses profile-local JSON defaults, derives request host scope from the URL, and imports supported Chrome “Copy as cURL” requests as editable drafts. Credential values use secret references and are not included in request logs or exports.
- Browser Automation is now a Playwright Test Explorer for a selected existing project: files are sections, tests are rows, tags are managed by Automator, and users can add test files/tests and run a file, test, or tag group.
- Workflows have a saved Variables section with typed JSON values, including arrays, used as the initial workflow object.
- Scheduler can target either a workflow or a saved Script Runner profile while keeping old workflow-only records readable.
- Slot 7 is a persisted Work Time log with start/stop, required description, optional tags, history, resume/discard for a pending entry, and restart recovery. Pomodoro controls are no longer presented.
- The app has a separate resizable Workspace window for editing complex tabs. It keeps local tab selection and visibility independent of the quick launcher. Tabs 2–9 are available there.
- Slots 2–7 expose a shared keyboard command search; a unique match can run with Enter, ambiguous results require choosing an action, and script/network/browser actions require explicit confirmation.
- Script Runner already supports Python, Bash, and PowerShell, with user-provided interpreter defaults remembered by runtime.
